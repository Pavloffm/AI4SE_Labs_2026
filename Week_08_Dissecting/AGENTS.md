# Coding-assistant exercises

- Read `Assignments/readme.md` before working on this week's tasks. These exercises ask the student to inspect and configure their own coding assistant.
- Distinguish steps the assistant can perform from interactions the student must complete, such as capturing a screenshot of their interface. Provide instructions for the latter rather than claiming completion.
- Check the installed assistant's current official documentation before describing supported features, commands, or configuration fields. Include a source link in feature reports.
- Keep reports as short as the task requests and place evidence in the corresponding `Assignments/Task_*/` directory.
- Preserve configuration changes through completion of the assignment, as the weekly readme requires. Obtain authorization before changing settings outside this repository.
- Redact credentials and personal details from submitted configuration and screenshots while preserving the settings needed to demonstrate the feature.
