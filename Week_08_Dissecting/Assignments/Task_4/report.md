# Task 4 — OpenCode Profiles

OpenCode supports custom profiles through [agents](https://opencode.ai/v2/docs/agents), but after considering alternatives, I still prefer its existing Plan and Build modes for my tasks. In Plan mode, I discuss the task with the agent and use the grilling skill for complex decisions to clarify how I want things done. I then switch to Build mode for implementation, using skills and subagents with a maximum delegation depth of two. This separation feels simpler to me, and I do not currently see a need for another mode.

I have not created a new profile, so this report records why it is not possible, I can make it but it don't make much practical sense.
